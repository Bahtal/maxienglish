# maxienglish — Telegram Mini App на Vue

Кабинет репетитора по английскому для учителя и учеников. Интерфейс собран на Vue 3, сборка — Vite, стили компонентов — SCSS Modules. В обычном браузере можно переключаться между демонстрационными ролями; внутри Telegram используется Telegram Mini App и подключение к Supabase.

## Локальная разработка

Нужен Node.js 20.19+ или 22.12+ и npm. В папке проекта выполните:

```bash
npm install
npm run dev
```

Vite покажет локальный адрес, обычно `http://localhost:5173`. Для браузерной разработки достаточно локального адреса. Telegram Mini App требует HTTPS-адрес, поэтому локальный сервер сам по себе не откроется внутри Telegram.

Для производственной сборки:

```bash
npm run build
```

Сборка появится в `dist/`. Firebase Hosting публикует только эту папку.

## Публикация на Firebase

```bash
npm run build
npx firebase-tools@latest deploy --only hosting
```

Настройки проекта Firebase хранятся в `.firebaserc`. После успешной публикации открывайте адрес проекта `https://maxienglish-33b6c.web.app`. Netlify больше не участвует в этой сборке и публикации. Команда `update bot`, если она настроена в оболочке, сама не переключилась с Netlify: для публикации используйте две команды выше или отдельно замените локальный алиас.

## Структура приложения

- `index.html` — точка входа Vite и Telegram Web App SDK.
- `src/App.vue` — точка сборки: создаёт общее состояние и подключает оболочку.
- `src/pages/` — отдельная страница для каждого экрана и роли: главная ученика/учителя, ДЗ, календарь, списки учеников, профили и выбор темы.
- `src/components/layout/` — оболочка, боковое меню, шапка, нижняя навигация, уведомления и общие стили приложения.
- `src/components/student/`, `teacher/`, `calendar/` — небольшие блоки соответствующих страниц: карточки, расписание, история и формы.
- `src/components/modals/` — содержимое каждого диалога: урок, ДЗ, оплата, ученик и профиль.
- `src/composables/useWorkspace.js` — общее состояние приложения, действия, авторизация Telegram и синхронизация с Supabase.
- `src/utils/appConfig.js` — форматирование дат и чисел, подписи статусов и настройки тем.
- `src/utils/demoData.js` — начальные демонстрационные данные для локального режима.
- `src/components/AppButton.vue` — кнопка с вариантами, размером, цветом и состоянием загрузки.
- `src/components/SegmentedToggle.vue` — переиспользуемый переключатель вариантов.
- `src/components/ValidatedField.vue` — поле ввода/textarea с ограничением длины и пропсами `validator`, `validationType`, `allowedColors`.
- `src/components/HomeworkRow.vue` — строка задания.
- Стили лежат в `<style lang="scss" module>` тех Vue-компонентов, к которым относятся. Базовые правила приложения находятся в `src/components/layout/AppShell.vue`.
- `src/supabase.js` — клиент Supabase с публичным publishable key. Секретный ключ сервиса и токен Telegram-бота здесь хранить нельзя.
- `supabase/` — SQL-миграции и Edge Function. Эта папка не включается в `dist` и не публикуется Firebase Hosting.

## Возможности Vue-версии

- ученический и учительский кабинеты с переключением роли в локальном демо;
- главная, домашние задания, полный календарь, профиль, тема оформления и уведомления;
- просмотр задания, вложения и отметка «Выполнено»;
- список учеников, профиль ученика и переход в Telegram-чат при наличии username;
- создание учеников без ручного поиска Telegram ID: учитель отправляет одноразовую ссылку-приглашение;
- заявки на абонементы и подтверждение оплаты;
- индивидуальная цена урока и абонементы для отдельного ученика с наследованием общего прайса;
- создание и перенос уроков с длительностью по умолчанию из настроек преподавателя, отмена урока и отметка оплаты;
- настройки профиля учителя, предмета, опыта, формата занятий, правил, длительности, цены и пакетов уроков;
- общая ссылка Zoom преподавателя и отдельная ссылка на доску для каждого ученика;
- темы `default` и `darked`; в авторизованном Mini App тема сохраняется в профиле Supabase;
- локальный демо-режим хранит изменения в `localStorage` этого браузера.

## Supabase и вход через Telegram

Проект Supabase и его Edge Function остаются источником удалённых данных; Firebase здесь раздаёт только собранный интерфейс. На уже настроенной базе не повторяйте старые скрипты: примените `supabase/project-integrity-fixes.sql`, если ещё не запускали, затем `supabase/student-individual-pricing.sql` и `supabase/past-lesson-deletion.sql`. Для новой базы используйте файлы из `supabase/` по очереди: `schema.sql`, `link-student-accounts.sql`, `telegram-identity.sql`, `profile-avatar.sql`, `teacher-profile-and-lesson-flow.sql`, `lesson-links.sql`, `telegram-notifications.sql`, `telegram-notification-fixes.sql`, `student-invitations.sql`, `student-confirmation-and-history.sql`, `service-role-permissions.sql`, `realtime-publication.sql`, `theme-preferences.sql`, `project-integrity-fixes.sql`, `student-individual-pricing.sql`, `past-lesson-deletion.sql`.

В Supabase Edge Function Secrets должны быть настроены `TELEGRAM_BOT_TOKEN` и `TELEGRAM_AUTH_SECRET`. Токен бота, ранее отправленный в переписке, необходимо отозвать в BotFather и заменить секрет в Supabase. Код Mini App передаёт подписанный `initData` функции `link-telegram`; учитель и ученик входят через Telegram без почты и пароля.

Чтобы подключить ученика, учитель создаёт его профиль в приложении и отправляет ссылку-приглашение. Ученик открывает её в Telegram и нажимает Start; Telegram ID привязывается автоматически. Установка миграции, webhook и публикация этой функции описаны в `supabase/student-invitations-setup.md`. Чтобы назначить собственный аккаунт учителем, приложение показывает SQL-команду для Supabase SQL Editor. Для сохранения индивидуальной темы в уже созданной базе выполните `supabase/theme-preferences.sql`, если ещё не запускали.

### Уведомления Telegram-бота

Отправка сообщений работает через Supabase Edge Function; постоянно включённый компьютер или отдельный VPS не нужны.

1. Для ранее настроенной базы выполните `supabase/project-integrity-fixes.sql` в SQL Editor. Он защищает повторные заявки на оплату и подтверждение, проверяет посещаемость и пересечения уроков, а также обновляет очередь напоминаний. `supabase/telegram-notification-fixes.sql` повторно выполнять не нужно, если он уже применён.
2. Создайте случайный секрет командой `openssl rand -hex 32`. Добавьте его в Supabase **Edge Function Secrets** под именем `TELEGRAM_CRON_SECRET`. Не отправляйте значение в чат.
3. Из корня проекта задеплойте обновлённую функцию:

   ```bash
   npx supabase functions deploy telegram-notifications --project-ref gxcpnixtjqpjgonpidix
   ```

4. Откройте `supabase/telegram-notifications-cron.sql`. Замените `REPLACE_WITH_SUPABASE_PUBLISHABLE_KEY` на publishable key проекта, а `REPLACE_WITH_TELEGRAM_CRON_SECRET` на тот же случайный секрет из шага 2. Выполните SQL один раз. Он запускает проверку очереди каждую минуту.
5. Учитель и каждый ученик должны сами открыть личный чат с `@MaxiEnglish_bot` и отправить `/start`: Telegram не разрешает боту первым начинать личный диалог. Если ученика добавили раньше, приветствие и другие сообщения останутся в очереди и будут повторяться раз в 5 минут до 30 дней, пока ученик не нажмёт «Запустить».

Функция рассылает новые записи из `notifications`, напоминает обоим участникам за час до урока, сообщает ученику при переходе к одному или нулю оплаченных занятий и отправляет учителю отчёт по понедельникам в 09:00 его часового пояса. В отчёте — проведённые и отменённые уроки, подтверждённые оплаты, число занятий на следующие 7 дней и число учеников без оплаченных занятий. Cron опрашивает очередь раз в минуту, поэтому обычно сообщения приходят в течение минуты. Очередь и ошибки можно проверить в таблице `telegram_message_queue`.

Кнопка чата открывает Telegram, а оплаты пока отправляются как заявки преподавателю; реальный эквайринг в этот бот не добавляется.
